# MostBox Android 开发验收

当前验证对象是全功能开发版，不是已完成适配的 Google Play 或中国大陆商店版。工程入口为 `app/`；三个发行目标见[开发与发行路线](roadmap.md)，已有结果与未覆盖项见[验证状态](validation-status.md)。

## 构建与安装

从仓库根目录进入 `app/` 后运行：

```bash
cd app
npm test
npm run typecheck
npm run bundle:android
npm run build
```

内部 APK 位于 `app/dist/`。正式签名与 AAB 构建入口见[移动端 README](../app/README.md)，内部 APK 的成功构建不能代替正式签名、商店审核或地区适配。版本与构建号以当前项目配置和最终安装包为准。

全功能版默认进入聊天，底栏为“聊天 / 通讯录 / 发现 / 我”；文件与传输入口在发现，节点与账号入口在我。冷启动使用本机 Bare Worklet，远程 daemon、邀请码、签名身份、连接历史和节点切换按实际入口验收。

## 首要闭环：三节点接力

从仓库根目录运行：

```bash
node scripts/android-real-p2p-seed.mjs --handoff-check
```

1. 桌面 A 发布文件；手机 B 打开 `most://`，先显示文件名、CID 和下载确认。
2. 用户确认后传输，完成后重算 CID，再写入 holding 并加入 topic。
3. 退出 A，B 保持前台；全新空数据目录的节点 C 必须从 B 下载并独立校验同一 CID。
4. 重启 B 再测试，确认完整副本可读、topic 恢复；不能仅凭“做种中”文案宣布通过。

## 功能与故障矩阵

| 场景           | 通过标准                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 深链与已有文件 | 冷启动/运行中深链先确认；非法 CID 拒绝；metadata 存在但 blob 缺失时不能报告已有、导出或做种                            |
| 大文件与恢复   | 256MiB 和 2GiB 以上发布、下载、校验、保存与接力；记录内存，在受控字节切点停止/切网后恢复且 CID 一致                    |
| 系统文件流程   | 保存、打开和分享完整副本；同名不覆盖原文件；取消、磁盘满、权限撤销及输出损坏不误报成功，清理不完整输出                 |
| 频道文本       | 创建/加入、分页历史、离线后补历史；文本幂等发送、失败重试不重复，节点切换后不混入旧响应                                |
| 会话状态       | 节点间草稿和会话隔离；未读、删除会话后新消息恢复、频道分享和键盘避让符合实际操作                                       |
| 照片和语音消息 | 用户选图/拍照或录音后确认发送，附件按 CID 校验；试听、取消、重试、播放和后台停止录音可用                               |
| 实时通话       | 双真机实际双向音频、静音恢复、拒绝权限、挂断释放和切网恢复；仅参与者/信令同步不算通过                                  |
| 远程节点       | 登录、退出、连接与切回本机有等待反馈；重复点击锁定；断网、503 和超时后可重试且保留输入与原有数据                       |
| 提醒与权限     | 本地消息提醒由用户开启；仅在使用相应功能时申请相机、麦克风等权限，拒绝后能返回可用状态                                 |
| 生命周期       | 前后台、进程停止后任务与 holdings 可恢复；后台保持由用户主动开启，持续通知可停止，切换远程节点后停止本机保持           |
| 网络           | Wi-Fi、蜂窝、跨网双机与冷启动分别记录实际提供者、连接时间、传输路径和最终 CID；不能用缓存或后续 Wi-Fi 完成替代蜂窝通过 |
| Android 运行库 | Android 10 与较新系统 arm64 真机冷启动、重启、发布与接力；记录系统、ABI 与实际打包的 Bare 运行库                       |

现有文件类型策略仍按代码执行；是否调整属于后续产品或商店适配决策。本次文档清理不改变传输范围、权限或功能开关。

后台保持不承诺永久在线、系统清理后独立恢复或所有系统版本都通过。最新运行库、连续息屏、无充电和系统超时均需单独测试。中继配置与实际中继传输也应分别记录。
