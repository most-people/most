# MostBox Android 内测验收清单

本清单用于 Android Google Play 候选版真机验收。当前 Android 版本是 MostBox 去中心化聊天与文件传输应用，包含文件发布与下载、本机和远程节点、账号身份、频道聊天、传输管理及 P2P 诊断能力。原生包与 Web 端共享远程节点、身份和聊天协议；本机节点在应用进入后台时仍受系统调度限制，远程 daemon 可按自身策略继续传输。

最近一次多节点实测见 [2026-09-12 Android 三节点验收记录](android-multi-node-2026-09-12.md)，包含双向做种交接、Android 重启恢复、三端聊天和附件校验，以及未覆盖项目。

2026-10-08 流式系统保存和附件接收入口的改动见 [移动文件体验实施记录](mobile-file-experience-2026-10-08.md)。[2026-10-09 ARM64 真机回归](android-physical-2026-10-09.md)已通过附件接收、系统打开、发布者退出后的手机种子接力，以及 256MiB / 2112MiB 发布和系统保存；大文件网络下载、连续内存峰值、提供者故障和恢复场景仍待补。后续 Android 验收仅使用真机。

## 构建与安装

先运行移动端测试和内部 APK 构建：

```bash
cd app
npm test
npm run typecheck
npm run bundle:android
npm run bundle:ios
npm run build
```

内部 APK 位于 `app/dist/`，用于真机功能回归。Google Play 候选包必须使用独立 upload key 运行 `npm run build:play` 生成 `.aab`，不得上传 debug 签名 APK。

安装后确认默认进入“聊天”页，底部显示“聊天 / 通讯录 / 发现 / 我”四个入口；文件、传输及节点状态从“我”进入，连接管理在节点页，并最终显示当前连接状态。最近内部包的真机验证及已知限制见 [2026-10-14 后续记录](mobile-followup-2026-10-14.md) 和 [双 Android 真机与蜂窝后台验证](mobile-two-android-2026-10-14.md)。

## 商店能力与连接范围

1. 节点页展示本机和远程节点状态、holding、传输和日志；支持远程地址、邀请码、账号身份登录、连接历史和节点切换。
2. 冷启动创建本机 Bare Worklet 节点；用户可在节点页连接 HTTP(S) 或 WebSocket daemon，并在本机与远程节点之间切换。
3. 原生 bundle 内置远程核心、身份和连接面板实现，不依赖 Expo Web；Web 与 Android 使用相同的远程 API、WebSocket 和签名协议。
4. 聊天频道和附件使用当前活动节点（本机或远程）；语音信令入口在已连接远程节点的频道中提供。未连接或未登录时，界面应明确提示并提供返回节点页的入口。

## 最高优先级：前台做种交接

从仓库根目录运行：

```bash
node scripts/android-real-p2p-seed.mjs --handoff-check
```

验收步骤：

1. 桌面发布者发布文件并打印 `most://` 链接。
2. Android 点击“接收文件”，输入链接并先执行“检查链接”。
3. 确认页展示文件名和 CID；只有点击“确认下载”后才开始传输。
4. 下载完成后 holding 状态为“做种中”，topic 已加入，CID 与桌面一致。
5. 关闭原桌面发布者，保持 Android 在前台。
6. 让脚本启动干净 verifier；verifier 必须从 Android 下载并重算出相同 CID。

## 必测场景

| 场景             | 通过标准                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| Android 发布文件 | 系统文件选择器出现；发布完成后生成 holding、复制 `most://` 链接并加入 CID topic                              |
| 手工输入链接     | `most://`、网页入口和裸 CID 均可解析；非法 CID、额外路径和额外参数被拒绝；有效输入先展示确认信息             |
| 外部深链         | 冷启动和运行中打开 `most://` 都只进入确认页；用户点击确认后才开始下载                                        |
| 下载校验         | 下载完成后重算 CID；不一致时不得保存或做种                                                                   |
| 已有文件         | 同一 CID 已在本机时不重复下载                                                                                |
| 文件策略         | 用户选择或链接声明的 APK、AAB、XAPK、DEX、EXE、脚本等类型在传输前被拒绝                                      |
| 保存和分享       | 系统分享面板可接收文件；Storage Access Framework 可把副本保存到用户选择的目录                                |
| 删除 holding     | holding 消失并停止做种；已保存到用户目录的副本保留；相同链接之后可重新下载                                   |
| 重启恢复         | App 重启后恢复 holdings，并重新 join 对应 CID topic                                                          |
| 远程节点连接     | 输入远程地址和邀请码后完成身份登录；连接状态、节点切换和断线重连反馈正确                                     |
| 操作等待反馈     | 登录、退出、节点连接和本机切换显示相应转圈与等待提示；重复点击不重复执行，失败后恢复操作且保留地址           |
| 远程文件与传输   | 连接远程节点后可查看远程 holding、发起发布/下载、取消和重试；状态与节点页一致                                |
| 聊天频道         | 创建或加入频道、分页读取历史、发送文本和 `most://` 附件；频道 ID 大小写规范化后仍能持续收发消息              |
| 会话状态         | 每个频道保存独立草稿；本机与远程节点隔离；重启恢复，未读提示不受搜索过滤影响                                 |
| 频道分享与搜索   | 信息页和通讯录复制真实频道名称；复制内容可加入或搜索，系统分享可取消；备注不替代频道标识                     |
| 删除会话         | 只移除列表条目；频道与历史保留，新他人消息使会话重新出现；历史、自己消息和系统事件不触发恢复                 |
| 发送重试         | 模拟保存消息后响应丢失，原文本或录音保留；重试得到同一消息，语音不重复上传，频道历史不新增重复条目           |
| 照片附件         | 系统相册选择或拍摄后发布；接收后 CID 校验通过才显示本机预览；拒绝相机权限后仍可用文件选择器                  |
| 语音消息         | 按住录制，松手试听、取消或发送；音频按 CID 校验、默认做种；聊天内播放、暂停和重播，后台不继续录制            |
| 消息提醒         | 默认关闭；开启后后台新消息出现静音通知，点击进入正确频道；旧历史、自己消息、前台阅读不重复提醒；关闭后停止   |
| 语音信令         | 在聊天频道中加入、离开、静音和恢复语音状态；参与者状态与信令事件同步                                         |
| 前后台切换       | 返回前台后本机节点和 topic 自动恢复；远程节点按 daemon 能力继续后台传输并正确显示状态                        |
| Android 后台保持 | 本机 ready 时主动开启持续通知；息屏可向空白节点传播并通过 CID 校验；通知停止及节点切换移除服务，前台做种保留 |
| 商店能力边界     | AAB 内可访问本机/远程节点、账号、聊天、文件和传输入口；每项能力都能从对应入口完成闭环                        |
| 可见性           | 能查看 CID、文件大小、做种状态、topic 状态、peer 数、传输进度和基础日志                                      |
| 政策入口         | 节点页可打开隐私政策、使用条款和问题反馈页面                                                                 |
| 权限             | 仅使用拍摄时请求相机、录音时请求麦克风；拒绝权限能恢复；不申请通讯录、短信、位置、悬浮窗或全盘存储权限       |

## Google Play 候选包检查

上传 Internal testing 前确认：

- `.aab` 的 package name 是 `most.box`。
- `versionCode` 大于 Play Console 中已上传的所有版本。
- `targetSdkVersion` 和 `compileSdkVersion` 均为 36。
- AAB 使用独立 upload key 签名，不是 Android debug key。
- Play App Signing 已启用。
- 首次安装或政策版本更新后，未同意隐私政策前不创建或启动 P2P 核心；拒绝后退出应用。
- `https://most.red/privacy/`、`https://most.red/terms/` 和 `https://most.red/support/` 可从公网无登录访问。
- 提供至少两个有在线种子的审核测试链接，并在审核期间保持可下载。
- 商店截图只展示当前 AAB 实际存在的聊天、文件、传输和本机/远程节点能力。

详细提交字段见 `docs/google-play-submission.md`。
