# Most 完整版 APP 与墨盒路线图

本文是 0.5.x 之后的实施基线。`V0.5.0` 的商店材料保留为历史证据，不再作为完整版功能边界。

墨盒大陆版的构建、功能收敛和备案材料见 [`docs/mohe-release-checklist.md`](mohe-release-checklist.md)。

## 当前已落地

- `mobile/app` 已支持 Most/墨盒 product profile，可按构建环境切换名称、包标识、法律入口和 EAS profile；两者继续使用 `most://`。
- 移动端已加入聊天 HTTP/WS 协议客户端基础，包括 CID 附件校验、幂等消息 ID、历史分页、事件去重、断线重连和订阅重放。
- 传输页已显示队列总进度、进行中/完成/失败数量，并对异常进度进行边界处理。
- Most 国际版原生入口已支持远程 daemon 连接、邀请码、账号签名、节点历史和切回本机；墨盒 profile 默认关闭远程能力。
- Most 国际版已接入基础聊天页面，可加入频道、读取历史、发送文本、发送 `most://` 文件附件并接收实时消息；语音和成员能力仍在后续阶段。
- 移动知识库已支持 Obsidian 风格双链解析、相对路径解析、未解析链接提示和反向链接导航。
- 移动知识库已加入 Git 状态、提交历史、差异规范化和行数摘要模型，为后续 Git 操作界面与远程 API 对齐提供稳定数据边界。

## 产品分层

| 能力                               | Most 国际版                  | 墨盒大陆版         | 共享约束                                         |
| ---------------------------------- | ---------------------------- | ------------------ | ------------------------------------------------ |
| 文件发布、下载、CID 校验、自动做种 | 开放                         | 首版开放           | `most://`、CID、topic 和 Hyperdrive key 保持兼容 |
| 本地知识库与 Git                   | 开放                         | 首版开放           | 本地数据可迁移，失败恢复前数据不变               |
| 聊天、附件、语音                   | 聊天与附件已开放，语音规划中 | 合规评估后开放     | 复用 native chat protocol                        |
| 远程 daemon、管理台、MCP           | 规划开放                     | 默认关闭，逐项评估 | 远程请求必须签名并受 scope 限制                  |
| Web3 工具箱                        | 独立入口                     | 默认关闭           | 不成为文件或知识库前置条件                       |
| AI、组织协作、知识网络             | 后续版本                     | 后续版本           | 当前不作为已实现能力宣传                         |

## 实施阶段

1. **基线与产品 profile**：统一版本源，建立 Most/墨盒 profile、功能矩阵、数据 schema 迁移和独立构建产物。
2. **移动文件生产能力**：文件夹/批量、队列、断点恢复、空间检查、通知、前后台恢复、App Links/Universal Links。
3. **知识库对齐**：Wiki 双链、反向链接、Git 提交/历史/差异/恢复、备份与迁移。
4. **移动聊天**：频道、历史分页、幂等发送、附件 CID、成员标签、@提及、语音和重连。
5. **国际版工具箱**：身份/资料、远程 daemon、管理台、MCP 和 Web3 独立入口。
6. **墨盒发行**：独立包名、Bundle ID、图标、法律页、客服/投诉入口、备案、签名和商店材料。
7. **验收发布**：双品牌真机矩阵、三节点接力、升级迁移、隐私/商店/备案一致性和发布门禁。

## 不变量与非目标

- 下载必须由用户确认，完成后必须重算 CID；校验失败不得保存或做种。
- 可用性只来自当前在线种子，不承诺永久存储或长期后台运行。
- 不加入公开资源目录、推荐、上链存储、支付、质押、订单或云盘主流程。
- 墨盒继续兼容 `most://`，品牌差异通过构建 profile 和法律/服务配置表达。

## 发布门禁

任何加入账号、推送、分析、云服务、中心化日志或后台常驻的改动，都必须同步更新隐私政策、商店申报、权限说明和测试矩阵。Most 与墨盒的软著、备案材料和签名指纹必须按品牌与版本分别归档。
