# MostBox DChat 与文件传输路线图

本文是当前 MostBox 移动端和桌面端的实施基线。产品以 DChat 为方向，核心是去中心化频道聊天，文件传输作为聊天附件和独立分享能力。

## 当前已落地

- Most/墨盒 product profile 可按构建环境切换名称、包标识、法律入口和 EAS profile；分享协议继续使用 `most://`。
- 移动端支持聊天 HTTP/WS 协议客户端基础，包括频道历史分页、幂等消息 ID、事件去重、断线重连、订阅重放和 CID 附件校验。
- 传输页显示队列总进度、进行中/完成/失败数量，并对异常进度进行边界处理。
- Most 国际版支持远程 daemon 连接、邀请码、账号签名、节点历史和切回本机；墨盒 profile 对不支持聊天的构建默认进入文件入口。
- Most 国际版默认进入聊天，可加入频道、读取历史、发送文本、发送 `most://` 文件附件并接收实时消息；语音信令与参与者状态保持现有能力，原生音频适配不属于本轮目标。

## 产品分层

| 能力                               | Most 国际版                    | 墨盒大陆版          | 共享约束                                         |
| ---------------------------------- | ------------------------------ | ------------------- | ------------------------------------------------ |
| 去中心化频道聊天                   | 默认入口，支持历史、文本和附件 | 按合规评估开放      | 复用现有 native chat protocol                    |
| 文件发布、下载、CID 校验、自动做种 | 开放                           | 首版开放            | `most://`、CID、topic 和 Hyperdrive key 保持兼容 |
| 传输与节点管理                     | 本机和远程 daemon              | 按构建 profile 控制 | 连接状态和权限边界可见                           |
| Web3 工具箱                        | 独立入口                       | 默认关闭            | 不成为聊天或文件前置条件                         |
| MCP                                | 受控 daemon 工具               | 默认关闭            | 复用现有文件 API 和权限模型                      |

## 实施阶段

1. **聊天主线**：频道、历史分页、幂等发送、附件 CID、断线重连和三个节点传播。
2. **文件主线**：发布、下载、完整性校验、默认做种、退出交接和移动端保存/分享。
3. **移动端验收**：Most 默认聊天，文件和传输保持独立入口；不支持聊天的 profile 默认文件入口。
4. **节点与工具**：身份、远程 daemon、管理台、MCP 和 Web3 保持独立入口。
5. **发行验收**：双品牌真机矩阵、升级清理、隐私/商店材料和发布门禁。

## 不变量与非目标

- 下载必须由用户确认，完成后必须重算 CID；校验失败不得保存或做种。
- 可用性只来自当前在线种子，不承诺永久存储或长期后台运行。
- 不加入公开资源目录、推荐、上链存储、支付、质押、订单或云盘主流程。
- 本轮不新增私聊、通讯录、未读统计或端到端加密；继续沿用现有 P2P 频道协议。

## 发布门禁

任何加入账号、推送、分析、云服务、中心化日志或后台常驻的改动，都必须同步更新隐私政策、权限说明和测试矩阵。Most 与墨盒的软著、备案材料和签名指纹必须按品牌与版本分别归档。
