# P2P 风险红线

MostBox 以去中心化频道聊天为核心，支持用户主动分享自有文件；它不是资源平台、云盘或永久存储服务。所有产品、文案和代码改动都必须守住以下边界。

## 必须保持

- 用户主动选择文件，主动复制或打开 `most://` 链接。
- 下载前需要用户确认；下载后重算 CID，校验通过才保存和做种。
- `most://` 链接和 CID 即访问权；泄露后其他人可尝试下载。
- 只说明当前在线种子带来可用性，不承诺永久保存或长期后台做种。
- 隐私政策披露 P2P/DHT 所需的 IP、topic、连接时间等网络元数据。
- 官网和商店材料保留版权、滥用或问题反馈入口。

## 禁止方向

- 不做公开资源目录、内容搜索、推荐、排行榜或热门内容。
- 不运营官方内容库、官方长期做种服务或代用户保存文件。
- 不自动下载陌生内容，不绕过用户确认。
- 不用电影、音乐、游戏、破解软件等高版权风险素材做示例或宣传。
- 不宣传规避审查、匿名下载、侵权传播或替代 BT 资源站。
- 不把 Web3、账号、付费、赏金或订单接入文件分享主流程。

## 变更门槛

涉及内容发现、公开分享页、中心化中继/日志、账号、举报、付费、长期后台做种或官方种子时，先做合规评估，再改代码、README、隐私政策和商店文案。

## 变更记录

### 2026-11-16 默认启用官方盲中继

- 决定：客户端默认使用 Most.Box 运营的 HyperDHT 盲中继（`scripts/blind-relay.js`，公钥 `DEFAULT_RELAY_PUBLIC_KEY`）。Hyperswarm 只在本机 NAT 随机分配端口或打洞失败时经中继连接，打洞成功后改为直连。原因：双方都在对称 NAT 后时无中继 0/30 可用，下载者单方在对称 NAT 后时无中继 287/300、有中继 300/300（见 `docs/validation-status.md` F5）。
- 中继能看到：双方的 IP 与端口、连接公钥、连接时间与流量大小。
- 中继看不到：文件与消息内容（转发的是双方已加密的连接字节）、CID、topic、文件名、频道名。中继不存储、不缓存、不做种任何文件，只记录会话计数。
- 为什么仍在红线内：中继不持有内容，不能列出或推荐内容，不是官方种子或代存服务；可用性仍只来自在线种子；不改变"用户主动分享、下载前确认、重算 CID"的流程。它新增的是一个能看到连接元数据的中心化方，已在 `PRIVACY.md` 和 README 披露，桌面/daemon 可关闭。
- 遗留：官网与商店托管的隐私政策、商店文案需在 `most.red` 同步。
