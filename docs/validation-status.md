本轮未覆盖或有限制：

- 真机在息屏测试后进入图案锁，无法由测试端解锁，之后的真机项（蜂窝、跨网、语音通话、权限拒绝、息屏长时测试）均未做；该设备上的后台保持已通过 force-stop 释放。
- 桌面端：Electron 能在隔离 profile 下启动并提供前端；没有对桌面窗口做逐项手工验收。
- 删除会话后收到新消息恢复未得出结论：Web 换到另一个 daemon 后缓存的频道在新 daemon 上不是成员，发送被服务端以 400 拒绝（代码会弹错误 toast，本轮没有观察到该提示），因此该用例未能用有效消息验证。
- 修复：下载进度对小文件显示 `0.0 / 0.0 MiB`，现按 B / KiB / MiB 显示。

## 当前未完成

- 移动实时通话：已有 offer / answer / candidate 信令，但尚无双真机原生媒体轨道、实时音频、音频路由与挂断释放的完整证据；本机模式信令桥接也待完成。
- 蜂窝连接与中继：重复冷启动、网络切换和原发布者退出后的空节点下载，分别记录公告、发现、握手、传输路径、耗时与最终 CID。
- Android 后台：当前运行库的连续息屏、无充电、系统清理、移除任务、通知权限拒绝和 Android 15/16 超时回调。既有 MIUI 自动清理失败仍是有效边界。
- iOS：按当前代码生成签名真机包，重新覆盖聊天、附件、本机/远程节点和生命周期；bundle 通过不能代替真机。
- 跨进程发送恢复：当前 UI 的失败发送尝试 ID 只在本次运行保留，不承诺进程重启后恢复未确认消息。
- 商店适配：两个商店版的功能边界、最终签名、隐私/SDK 申报、审核和大陆备案尚未完成，不将历史检查表当作通过证明。
