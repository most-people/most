## 不变的部分

- `most://<cid>?filename=...` 链接格式与 CID 参数（identifiers §1–2）。
- 文件模型：完整副本、下载后重算 CID、默认做种；每节点自己签名的 CID drive 与 drive 内路径 `/<cid>`。
- 两个长期 swarm 的分工；聊天 swarm 仍是换行分隔 JSON。
- 上游 Holepunch 协议栈。

## 兼容性

按已确认的决定：**不保留新旧兼容分支**。v1 与 v2 节点之间文件与聊天都不互通。v2 使用全新的 topic、Protomux 协议名和帧版本，v1 节点看到的是互不相干的 topic，不会误解析。

数据迁移在各文件「迁移」一节，参照 [CID drive 协议 v2](../../cid-drive-protocol.md) 的一次性迁移做法。
