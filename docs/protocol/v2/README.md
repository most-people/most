## 适用范围

线上格式以本套正文和 [现行测试向量](../vectors/README.md)共同核对。代码位置用于辅助核查，保留的行号是写作时快照，不作为协议定义。参考实现为桌面 Node daemon 与移动 Bare 核心；两端未实现或不一致处在正文明确列出，不宣称所有客户端已支持全部功能。语音和账号同步不属于独立实现的最小必选范围。

每篇内的历史迁移只适用于所列升级路径，不构成后续版本兼容承诺；旧源码和未签名向量只作回归或证据，不能据此实现新节点。已撤回的正文隐藏提案、收到回执等不列为当前线上能力。

## 互通与验收

- 按 [向量索引](../vectors/README.md)核对派生、载荷、签名和错误样例；向量通过只证明这些样例一致。
- 聊天 C1–C5、文件 F1–F5、故障注入和量化门槛按 [验收指南](../../acceptance.md)执行，不因文档合并而降低。
- 第三方能否仅凭公开材料互通、基础设施能否接替，以及维护交接，仍须 [公共协议独立性验收](../../acceptance.md#公共协议独立性验收)。现有测试与真实失败见 [验证状态](../../validation-status.md)。

HTTP/WebSocket 客户端接入另见 [客户端接口](../../native-chat-protocol.md)，节点运维见 [项目 README](../../../README.md)；这些入口不增加 P2P 的官方服务前提。
