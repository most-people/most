# Default avatar artwork

## Current avatars

Six AI-generated images supplied by the project maintainer for use as the default
avatars on 2026-11-26. These are not Noto Emoji or DiceBear artwork.

Each original was cropped to a square and resized to a 512 × 512 JPEG at quality 90. The source images remain outside the repository. Crop coordinates are in
source pixels, measured from the top-left corner.

## Noto Emoji

The earlier animal and mountain avatars use Noto Emoji SVG artwork by Google.
These files remain available for profiles that already use their URLs.
